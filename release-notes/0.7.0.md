# SFX Vault 0.7.0

Windows per-user installer and GitHub Releases updates for the approved V0.6 app.

- Standalone installer, Start Menu shortcut, optional desktop shortcut and uninstall.
- Settings → Updates & About: version, release notes, manual checks and opt-in launch checks.
- Approved downloads show progress and require SHA-256 verification before installation.
- Setup starts after the app exits; explicit confirmation covers preview and unsaved edits.
- Catalog backup before updating; application data retained through reinstall and uninstall.
- Existing audio, library management, metadata, imports and REAPER dragging are preserved.

Keep source audio in place. User data remains in %LOCALAPPDATA%\SFX Vault.
This is an unsigned Windows build. SHA-256 validates integrity, not publisher identity.
